# Festival Résonances

Intégration du site du festival Résonances — Sass, architecture SMACSS, convention BEM.

## Site en ligne
URL Vercel : https://resonances-om43vzmoi-mathurins-projects-c46a20b9.vercel.app/

## Installation
```bash
npm install
npm run sass:watch   # compile en continu pendant le développement
npm run sass:build   # compile une seule fois
```

Les sources sont dans `scss/`, le fichier compilé est `css/style.css` (ne jamais le modifier à la main).
Conventions de nommage : voir [NOMMAGE.md](NOMMAGE.md).
